# ZaloPay homepage

A responsive Angular landing page inspired by the supplied ZaloPay design brief. It uses a standalone Angular component, brand color tokens, and responsive CSS with no external image assets.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:4200/` after the Angular development server starts.

## Build

```bash
npm run build
```

The homepage is written in English and includes mobile navigation, an app wallet preview, service shortcuts, an interactive promotional carousel, trust highlights, partner marks, app download buttons, and a footer.
