About BotanyLabs

Dashmin is an admin dashboard template that was rebuilt as an Angular application. The whole dashboard shell - the fixed sidebar, the top navbar and the footer - lives in a single layout component, while the pages themselves are loaded on demand by the router.

Only the two links that are needed for now are kept: Home and About. Everything else from the original static template was left out.
