    5- Scenario: authors → books → reviews. An author has many books, and each book has many reviews (with a rating field):
        Write a single aggregation pipeline that returns each author with:
            - Their list of books
            - For each book, its average rating
            - A top-level field showing the author's overall average rating across all their books

        Hint: This needs nested `$lookup`s (books → reviews inside a pipeline), `$addFields` with `$avg` per book, then a second-level `$group` or `$avg` across the book averages back at the author level. This is the closest MongoDB gets to a 3-table JOIN with aggregation math on top.


===========
- - - - - -
[
  {
    $lookup: {
      from: "books",
      localField: "_id",
      foreignField: "authorId",
      pipeline: [
        {
          $lookup: {
            from: "reviews",
            localField: "_id",
            foreignField: "bookId",
            pipeline: [],
            as: "reviews"
          }
        },
        {
          $addFields: {
            bookAvgRating: {
              $avg: "$reviews.rating"
            }
          }
        }
      ],
      as: "books"
    }
  },
  {
    $unwind: {
      path: "$books"
    }
  },
  {
    $group: {
      _id: "$name",
      books: {$push: "$books"},
      country: {$first:"$country"},
      authorAvgRating: {
        $avg: "$books.bookAvgRating"
      }
    }
  }, 
  {$sort: {
    "authorAvgRating": -1
  }}
]
